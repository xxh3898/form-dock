# 1. Product Definition

FormDock은 승인된 Creator가 설문을 만들고 공개 링크로 응답을 수집하고 결과를 조회·내보낼 수 있는 self-hosted 설문 플랫폼이다.

# 2. Why FormDock

개인 프로젝트, 시장조사, 마케팅 과제, 사용자 검증을 반복할 때 설문 제작·응답 관리 방식이 매번 달라지는 문제를 줄인다.

FormDock의 목적은 Google Forms나 Typeform을 완전히 대체하는 것이 아니다. 우리 프로젝트에서 반복되는 설문 작업을 공통 인프라로 만드는 것이 목적이다.

# 3. Primary Users

## Creator

- 서비스 운영자
- 운영자가 직접 승인한 사용자
- V1 공개 회원가입 없음

## Respondent

- 공개 링크로 접속
- FormDock 계정 불필요
- 모바일 우선 응답 경험

# 4. Core Values

- 재사용 가능한 설문 인프라
- 응답 데이터 직접 소유
- 단순한 운영
- 실제 사용 기반 확장
- Self-hosted first

# 5. Product Principles

1. Simple before flexible
2. Real usage before feature expansion
3. Data integrity over editing freedom
4. Private creator, public respondent
5. Self-hosted first
6. No unnecessary SaaS complexity

# 6. V1 Boundary

V1의 핵심은 네 가지다.

1. Survey Builder
2. Public Survey
3. Response Collection
4. Result Dashboard / CSV Export

# 7. Initial Success

- 실제 설문 생성 가능
- 외부 Respondent가 모바일에서 정상 응답
- 응답 안정적 저장
- Creator 결과 조회
- CSV Export
- 최소 두 종류 이상의 실제 프로젝트에서 재사용

첫 dogfooding 후보는 Cubing Hub 사용자 검증 설문이다.

# 8. Non-goals

- 범용 기업용 설문 SaaS
- 결제/구독
- 공개 회원가입
- Workspace/Team
- Marketplace
- 마케팅 자동화
- AI 설문 플랫폼
